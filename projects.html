Project ideas

Six things I want to build — each small enough to finish in a week, each one teaching me one new thing.

  1. Planner with Alarms

    A plan for the day where every block gets a start time and an alarm, so the plan interrupts me instead of sitting quietly in a tab. Tomorrow starts as a copy of today.

    • HTML
    • JS
    • Web Audio
    • localStorage

  2. Word Well

    Flashcards for the words I keep forgetting. I type the answer, and the card comes back sooner if I miss it, later if I get it right.

    • JS
    • arrays
    • localStorage

  3. Timetable Grid

    My class schedule as a grid I can drag blocks around in, with a warning when two courses land in the same slot and a print view for the fridge.

    • CSS grid
    • drag events
    • JS

  4. Cleaning Duty Bot

    Posts tomorrow's cleaning duty to the class chat every evening and pings whoever is on, so the argument about whose turn it is ends before it starts.

    • Python
    • cron
    • webhook

  5. Quote Wall

    The quotes from this site as a wall of cards: one is picked at random, set in a shareable layout and exported to an image I can send to someone.

    • JS
    • Canvas
    • CSS

  6. Reading Log

    Every book I finish, with a bar per month and one sentence on what I took from it — a page that gets more useful the lazier I am about updating it.

    • JS
    • JSON
    • CSS

None of these is built yet. As each one ships it gets its own page and a line here.
